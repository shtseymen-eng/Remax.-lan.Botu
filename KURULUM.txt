RE/MAX İlan Botu V33 - Selenium MAX

Bu sürüm WhatsApp okuma motorunu, çalışan pregate-mail-bot yaklaşımına geçirir.

GITHUB'A YÜKLENECEKLER
1. src/remax_bot/whatsapp_selenium.py  (yeni)
2. pyproject.toml                       (üzerine yaz)
3. .github/workflows/main.yml           (üzerine yaz)
4. tests/test_v33_selenium_max.py       (yeni)

Ayrıca APP_PY_DEGISIKLIK.txt içindeki iki küçük app.py değişikliğini uygulayın.

KULLANIM
- Uygulamayı açın.
- BOTU BAŞLAT'a basın.
- Chrome WhatsApp Web açılır.
- İlk kullanımda QR kodu okutun.
- İstediğiniz grup veya özel sohbeti Chrome'da açın.
- Sohbete #Max başla yazın.
- Max aynı açık sohbete kendini tanıtarak cevap verir.
- Sonra #?, #danışmanlar, #izmit kiralık 55 bin vb. kullanılır.
- #Max durdur Max komut modunu durdurur.

NEDEN CHROME?
Pregate-mail-bot'ta çalışan yöntem Selenium + gerçek Chrome profilidir.
QWebEngine WhatsApp DOM okuyucusundaki kırılgan katman artık Max'in ana okuyucusu değildir.

ÖNEMLİ
GitHub Actions Selenium'u EXE ve APP içine paketler.
ChromeDriver dosyası sabit gömülmez. Selenium Manager kurulu Chrome'a uygun sürücüyü çözer.
Çalışacak bilgisayarda Google Chrome kurulu olmalıdır.
